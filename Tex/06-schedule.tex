\section{研究工作计划与进度安排}

结合课题研究目标、技术路线及已有科研基础，本课题围绕漏洞修复验证、漏洞自动修复和漏洞挖掘三个方向开展研究：

\begin{enumerate}

\item \textbf{2025.09 -- 2026.07：开展漏洞修复验证研究。}
完成补丁存在性测试系统评测与基于智能体的端到端补丁验证研究，形成相关论文成果。

\item \textbf{2026.08 -- 2027.03：开展漏洞自动修复研究。}
面向真实漏洞场景，研究智能体漏洞修复中的根因分析、补丁生成与修复验证方法，完善漏洞修复评测基准。

\item \textbf{2027.04 -- 2027.12：开展智能体漏洞挖掘研究。}
面向嵌入式设备、固件和受限二进制环境，研究基于行为约束与状态分析的漏洞自动发现方法。

\item \textbf{2028.01 -- 2028.06：完成论文总结与博士答辩。}
整理研究成果，完成博士学位论文撰写、修改及答辩工作。

\end{enumerate}
